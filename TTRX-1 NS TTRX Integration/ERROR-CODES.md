# RapidBridge error codes

Every `log.error` in the SuiteApp carries a unique STATIC `title`. Grep the code to land on the
exact line; the function name after it is for reading the log, not for finding the line.

`log.error` takes only `title` and `details` (SuiteScript 2.x, `N/log`). Everything else -
record ids, field names, the error message - lives INSIDE `details`:

```js
log.error({ title: 'RB-WRITE-042 writeReceiptAndLines',
  details: { context: 'itemreceipt/' + receiptId,
    error: (e && e.message) || String(e) } });
```

Titles are at most 99 characters (NetSuite truncates past that); the longest here is well under.
Regenerate this file when the scripts change - line numbers go stale, the codes do not.
